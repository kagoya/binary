# 0と1の実験室

2進数とは何か、なぜ計算できるのかを体験する日本語のインタラクティブ教材です。

**公開ページ： https://kagoya.github.io/binary/**

## できること

- 4ビットスイッチで0〜15を表す
- 2つのスライダーで足し算と繰り上がりを確認する
- XOR／AND半加算器と真理値表を操作する
- 解説つき3問クイズで理解を確認する

## 使い方

公開ページをブラウザで開いてください。`index.html` をダウンロードして直接開くこともできます。外部ライブラリや通信は不要です。

スマートフォン表示、キーボード操作、印刷に対応しています。Tabキーで移動し、ボタンはEnter／Space、スライダーは矢印キーで操作できます。

## 更新方法

`main` ブランチの `index.html` を更新すると、GitHub Pagesに自動反映されます。
